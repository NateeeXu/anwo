# Review fixes — security + product-QA pass (2026-11-04)

Outcome of the fix pass over the two-reviewer findings (security, product QA). Severity order: every critical and high
finding was addressed; mediums were fixed where the change was clearly correct; lows where the change was small.
Statuses: **fixed**, **partial** (the risky part is fixed; what is left is listed), **skipped** (with the reason).

Verification: `npm run typecheck` passes (shared, server, web), `npm test` 10/10, `npm run i18n:check` 0 problems
(4,300+ keys per locale), `npm run e2e` result at the end of this file. A throwaway API smoke script also replayed the
reviewers' live attacks against a fresh seed: the unsigned webhook (401), a second once-per-user promo (refused at
settlement), the plan-change wallet loop (no credit, upgrade returns an order to pay), rotating `X-Forwarded-For`
(still 429), forged `listing.view` beacons (dropped), a cross-site form POST to `/api/dev/login-as` (403), and a stolen
second session after a password change (401). All passed.

New schema (additive): `server/src/db/migrations/20_review_fixes.sql` (subscriptions.pending_plan_id / plan_changed_at,
boosts.price_cents, users.session_version, verification_requests.files_purged_at, partners.postback_secret) and
`20b_sponsorships.sql` (sponsorships, sponsorship_invoices).
